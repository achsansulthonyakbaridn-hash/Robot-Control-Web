MakeCode · Bluetooth UART

Protokol: key,value diakhiri newline. Cocok dengan extension Bluetooth di MakeCode.

Contoh kode MakeCode (JavaScript) 

            


            

              Cara pakai di MakeCode:

              1. Advanced → Extensions → cari Bluetooth → tambahkan

              2. Project Settings → No Pairing Required: Always

              3. Pakai block bluetooth uart write string / event on uart data received

              4. Format kirim: suhu,24.5 lalu newline · Format terima: lampu,1
            

          

        

      


      
      

        

          
Pemula

          
Cara pakai ACH Project

          

            Ikuti langkah-langkah di bawah dari nol. Nggak perlu jago coding — cukup ikutin aja.
          

        


        


          

            
1

            

              
Siapkan micro:bit & browser

              
    
                
  • Pakai browser Chrome atau Edge (Bluetooth web cuma support di situ).
    • 
                
  • Pastikan laptop/HP punya Bluetooth dan sudah nyala.
    • 
                
  • micro:bit harus sudah di-program pakai MakeCode (lihat langkah 2).
    • 
              

            

          


          

            
2

            

              
Program micro:bit di MakeCode

              
    
                
  1. Buka makecode.microbit.org → buat project baru.
    2. 
                
  2. Klik Advanced → Extensions → cari Bluetooth → tambahkan.
    3. 
                
  3. Klik gear ⚙️ di kanan atas → Project Settings → pilih No Pairing Required: Always.
    4. 
                
  4. Buka tab JavaScript, lalu di ACH Project buka Pengaturan → salin contoh kode → tempel di MakeCode.
    5. 
                
  5. Klik Download → copy file .hex ke micro:bit (seperti flash USB).
    6. 
              

              
💡 Kalau belum punya kode, mode Demo di Pengaturan bisa dicoba dulu tanpa micro:bit.

            

          


          

            
3

            

              
Sambungkan Bluetooth

              
    
                
  1. Colok / nyalain micro:bit.
    2. 
                
  2. Di ACH Project, klik tombol Sambungkan (sidebar kiri atau di Dashboard).
    3. 
                
  3. Browser akan munculin daftar perangkat → pilih yang namanya dimulai BBC micro:bit.
    4. 
                
  4. Kalau berhasil, status jadi Online / Terhubung (titik hijau).
    5. 
              

              
⚠️ Kalau gagal: pastikan Bluetooth laptop nyala, micro:bit masih nyala, dan coba refresh halaman.

            

          


          

            
4

            

              
Pahami format data (penting!)

              
Semua data dikirim dalam bentuk teks sederhana:

              
nama_key,nilai

              
Contoh:

              
    
                
  • suhu,24.5 → sensor suhu kirim angka 24.5
    • 
                
  • lampu,1 → nyalakan lampu (digital on)
    • 
                
  • lampu,0 → matikan lampu
    • 
                
  • kipas,512 → set kecepatan kipas (analog)
    • 
              

              
🔑 Key harus sama persis antara MakeCode dan widget di sini (huruf kecil).

            

          


          

            
5

            

              
Jenis widget

              
    
                
  • Sensor Input — menampilkan data dari micro:bit (angka + grafik).
    • 
                
  • Digital Output — saklar On/Off. Kirim 0 atau 1 (relay, LED, buzzer).
    • 
                
  • Analog Output — slider 0–1023 (atau range lain). Cocok buat motor, servo, LED redup-terang.
    • 
              

              
Widget bawaan: Suhu & Kelembaban (input), Lampu (digital), Kipas (analog).

            

          


          

            
6

            

              
Buat widget sendiri

              
    
                
  1. Buka menu Widget Kustom.
    2. 
                
  2. Isi Nama (bebas, contoh: “Relay Pompa”).
    3. 
                
  3. Isi Key (harus sama dengan kode MakeCode, contoh: pompa).
    4. 
                
  4. Pilih tipe: Sensor Input / Digital Output / Analog Output.
    5. 
                
  5. Klik Tambah — widget langsung muncul di Dashboard.
    6. 
              

              
🗑️ Widget buatan sendiri bisa dihapus lewat ikon sampah di pojok kartu.

            

          


          

            
7

            

              
Drag & tarik widget

              
Di Dashboard, tahan lalu tarik kartu widget untuk mengatur urutan (Sensor Input dan Aktuator punya area masing-masing).

              
✨ Urutan tersimpan otomatis di browser kamu.

            

          


          

            
8

            

              
Lihat log sinyal

              
Klik ikon gelombang di pojok kanan atas untuk buka panel Aktivitas Sinyal.

              
    
                
  • Masuk — data dari micro:bit
    • 
                
  • Keluar — perintah yang kamu kirim
    • 
                
  • Bisa kirim manual di kotak bawah, contoh: lampu,1
    • 
              

            

          


          

            
9

            

              
Tips kalau macet

              
    
                
  • Perangkat tidak muncul → pastikan program MakeCode sudah ada Bluetooth + “No Pairing Required”.
    • 
                
  • Terhubung tapi data kosong → cek Key sama, format key,nilai, dan ada newline di akhir.
    • 
                
  • Perintah tidak jalan → di MakeCode harus ada on uart data received yang baca key tersebut.
    • 
                
  • Coba dulu tanpa hardware → nyalakan Mode Demo di Pengaturan.
    •
